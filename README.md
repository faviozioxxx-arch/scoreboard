# Scoreboard

Скорборд для Paper 1.21.11 (Java 21). Показывает ник, пинг, здоровье, еду, мир,
наигранное время, уровень XP, координаты, направление взгляда, IP, порт,
версию, онлайн и RAM. Без красных цифр справа.

## Сборка через GitHub

1. Загрузите все файлы в репозиторий на GitHub.
2. Откройте вкладку **Actions**, выберите последний запуск **Build**.
3. Внизу страницы в разделе **Artifacts** скачайте `Scoreboard` — внутри `Scoreboard.jar`.
4. Положите jar в папку `plugins` сервера и перезапустите его.

## Сборка локально

```
mvn package
```

Готовый файл: `target/Scoreboard.jar`.

## Настройки

`plugins/Scoreboard/config.yml` — заголовок, цвета градиента и частота обновления.
